💰 Personal Budget Tracker – Python Data Analysis Project

📌 About the Project

The Personal Budget Tracker is a Python-based data analysis project designed to help users manage their personal income, expenses, and savings.

The project analyses financial transactions and provides useful information such as total income, total expenses, savings, average spending, and category-wise expense analysis.

It uses Python libraries and data storage techniques to maintain and analyse financial records.

🚀 Features

- Add income and expense transactions.
- View complete transaction history.
- Calculate total income.
- Calculate total expenses.
- Calculate total savings and saving percentage.
- Perform category-wise expense analysis.
- Find the highest and lowest expenses.
- Calculate average expenses.
- Search transactions by date.
- Perform monthly income and expense analysis.
- Store data using CSV files.
- Save and load Python objects using Pickle.

🛠️ Technologies Used

Technology| Purpose
Python| Core programming language
NumPy| Numerical calculations and statistics
Pandas| Data manipulation and analysis
CSV| Transaction data storage
Pickle| Saving and loading Python objects

⚙️ Installation and Setup

Step 1: Install Python

Install Python on your computer.

Step 2: Install Required Libraries

Open Command Prompt and execute:

pip install numpy pandas

Step 3: Download the Project

Clone the GitHub repository:

git clone YOUR_GITHUB_REPOSITORY_URL

Step 4: Run the Project

1. Open Python IDLE.
2. Open "budget_tracker.py".
3. Press "F5" to run the program.
4. Select an option from the main menu.
